# Data

Both files are the public panel datasets from the online complements to
Baltagi, B. H. (2001) *Econometric Analysis of Panel Data*, 2nd ed., Wiley,
as distributed in the R package `plm` (`data(Cigar)`, `data(Gasoline)`) and the
Rdatasets collection. They are copied here unchanged so the analysis runs offline.

References
